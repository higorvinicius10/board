# 🗂️ Java Task Board (Kanban CLI)

A command-line Kanban board application built in Java, applying Object-Oriented Programming (OOP) principles and layered architecture (Model, Repository, Service, and Application).

---

## 🚀 Features

- 📝 Add new tasks  
- 🔄 Move tasks between statuses (TODO → DOING → DONE)  
- 📊 Display tasks in a Kanban board format  
- ⚠️ Input validation and error handling  
- 💾 In-memory data storage  

---

## 🧠 Concepts Applied

- Object-Oriented Programming (OOP)  
- Layered architecture (MVC-inspired)  
- Encapsulation and abstraction  
- Collections (`Map`, `List`)  
- Java Streams API  
- Exception handling  
- Enum usage for state management
